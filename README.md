# The Cocker Spaniel
A simple, responsive front-end website dedicated to the Cocker Spaniel breed. Built with HTML and CSS, the site provides a visually engaging introduction to the breed, covering key characteristics such as size, lifespan, energy level, and temperament.

## Features:
- Responsive navigation bar with Home, About, and Contact links.
- Hero section with breed tagline and call-to-action.
- Breed stats overview (size, lifespan, energy, temperament).

## Technologies used: 
- HTML5
- CSS
